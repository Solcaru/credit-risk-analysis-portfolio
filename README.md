# credit-risk-analysis-portfolio

Análisis exploratorio de una cartera de crédito utilizando estadística y herramientas de análisis de datos.

## 1. Descripción del proyecto

Este proyecto busca analizar una base de datos de clientes de tarjetas de crédito para explorar las características de los clientes, su historial de pagos y su relación con el incumplimiento de las obligaciones crediticias.

El propósito es aplicar técnicas de análisis exploratorio de datos y estadística descriptiva para identificar patrones relevantes, construir indicadores y comunicar resultados que puedan contribuir a la comprensión del riesgo de crédito.

## 2. Objetivos

### Objetivo general

Desarrollar un análisis exploratorio de datos de crédito que permita caracterizar a los clientes e investigar qué variables están asociadas con el incumplimiento de los pagos.

### Objetivos específicos

- Examinar la estructura y la calidad de los datos.
- Identificar valores faltantes, registros duplicados y posibles inconsistencias.
- Describir las características de los clientes y su comportamiento de pago.
- Comparar las tasas de incumplimiento entre distintos grupos.
- Construir visualizaciones e indicadores para comunicar los resultados.
- Formular conclusiones y recomendaciones basadas en la evidencia disponible.

## 3. Fuente de datos

Se utilizará el conjunto de datos **Default of Credit Card Clients**, disponible en el repositorio académico UCI Machine Learning Repository.

Fuente oficial: https://archive.ics.uci.edu/dataset/350/defaultofcreditcardclients

Los datos incluyen información sobre límites de crédito, características demográficas, historial de pagos, montos facturados y pagos realizados por clientes de tarjetas de crédito.

La documentación de la fuente se consultará para comprender las variables, su significado y las condiciones de uso antes de iniciar el análisis.

## 4. Herramientas

Las herramientas se incorporarán progresivamente según las necesidades del proyecto.

- **SQL:** consultas y construcción de indicadores.
- **Python:** preparación de datos, análisis exploratorio y visualización.
- **pandas:** manipulación y transformación de datos.
- **Matplotlib y Seaborn:** visualización estadística.
- **GitHub:** documentación y control de versiones del proyecto.
- **Power BI:** posible extensión para desarrollar un dashboard interactivo.

## 5. Metodología

El proyecto se desarrollará mediante las siguientes etapas:

1. Comprensión del problema y de la fuente de datos.
2. Importación, exploración y documentación de las variables.
3. Evaluación de la calidad y preparación de los datos.
4. Análisis exploratorio y estadística descriptiva.
5. Análisis comparativo de los grupos de clientes.
6. Visualización e interpretación de los resultados.
7. Elaboración de conclusiones y recomendaciones.
8. Documentación del proceso para facilitar su reproducción.

Como extensión, se evaluará la posibilidad de desarrollar modelos predictivos de incumplimiento, siempre que los datos y la definición de la variable objetivo lo permitan.

## 6. Resultados esperados

- Un conjunto de datos documentado y preparado para el análisis.
- Código organizado y reproducible.
- Indicadores y visualizaciones estadísticas.
- Un informe con hallazgos, limitaciones y recomendaciones.
- Una base de trabajo para futuros proyectos de modelado predictivo.

## 7. Estado del proyecto

**Estado actual:** planificación y preparación del entorno de trabajo.

Los resultados y las conclusiones se incorporarán una vez finalizadas las etapas de exploración y análisis.

## 8. Consideraciones

El análisis distinguirá entre asociaciones estadísticas y relaciones causales. Los resultados dependerán de las características, la calidad y las limitaciones del conjunto de datos utilizado.

Este proyecto tiene fines educativos y de demostración de competencias en análisis de datos. Sus resultados no constituyen una evaluación crediticia real ni deben utilizarse directamente para tomar decisiones sobre personas.
